## 📌 Sobre o Desafio

Este repositório foi criado por **Leonardo Dumas** como parte do desafio da plataforma **DIO.me**, com o objetivo de praticar os conceitos essenciais de **Git** e **GitHub**, incluindo:

- Criação de repositório
- Versionamento de arquivos
- Uso de branches
- Commits e histórico
- Push e Pull
- Pull Requests
- Organização com Issues e Wiki

---

## 🧠 O que este repositório ensina

### ✔️ Git (local)
- Criar commits com mensagens claras
- Adicionar arquivos ao versionamento
- Criar e alternar entre branches
- Ver histórico de alterações
- Enviar atualizações para o GitHub (`git push`)
- Baixar atualizações do GitHub (`git pull`)
- Clonar repositórios (`git clone`)
- Remover arquivos versionados
- Criar e configurar `9.gitignore`0

### ✔️ GitHub (remoto)
- Criar repositórios profissionais
- Editar arquivos diretamente no navegador
- Criar Pull Requests e fazer merge
- Criar Issues para organizar tarefas
- Criar Releases para marcar versões
- Usar Wiki para documentação avançada
- Colaborar com outros desenvolvedores

## 🛠️ Comandos Git mais utilizados

### 🔹 Inicializar repositório
```bash
git init

🔹 Adicionar arquivos
git add .

🔹 Criar commit
git commit -m "Mensagem do commit"

🔹 Enviar para o GitHub
git push

🔹 Baixar atualizações
git pull

🔹 Criar nova branch
git checkout -b nome-da-branch

🔹 Trocar de branch
git checkout main

🔹 Ver histórico
git log
